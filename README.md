# «Из холодильника»: как запустить

Приложение — это несколько файлов, которые нужно один раз выложить в интернет. Сервер не нужен, всё бесплатно. Платите только OpenRouter за запросы к нейросети.

## 1. Ключ OpenRouter (10 минут)

1. Зарегистрируйтесь на https://openrouter.ai
2. Пополните баланс в разделе **Credits**. Для начала хватит $5. Заранее проверьте, что ваша карта или другой способ оплаты принимается: у зарубежных сервисов бывают ограничения в зависимости от страны.
3. Откройте https://openrouter.ai/settings/keys → **Create Key**.
   - Дайте ключу название, например «Жена».
   - Поставьте **Credit limit**, например $5. Больше этой суммы ключ потратить не сможет.
4. Скопируйте ключ (начинается с `sk-or-v1-…`). Его показывают один раз.

## 2. Выложить приложение на GitHub Pages (15 минут)

1. Зарегистрируйтесь на https://github.com
2. Справа вверху **+** → **New repository**.
   - Название: `kitchen` (или любое латиницей).
   - Видимость: **Public** (на бесплатном тарифе Pages работает только для публичных). В коде нет ключей и личных данных, так что это безопасно.
   - Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**.
4. Распакуйте архив `iz-holodilnika-app.zip` и перетащите в окно **всё содержимое** папки (файлы и папку `icons`). Нажмите **Commit changes**.
5. **Settings** → слева **Pages** → в «Branch» выберите `main` и `/ (root)` → **Save**.
6. Через 1–2 минуты сверху появится адрес вида `https://ваш-логин.github.io/kitchen/`.

## 3. Установить на телефон

1. Откройте адрес на телефоне.
2. **iPhone:** в Safari нажмите «Поделиться» → «На экран „Домой“».
   **Android:** в Chrome меню ⋮ → «Установить приложение».
3. Запустите с главного экрана, вставьте ключ, нажмите «Проверить и сохранить».

Модель выбирается автоматически (быстрая и недорогая). Поменять можно в **Настройки → Нейросеть**.

## Поделиться с друзьями

- **Настройки → Поделиться ссылкой.** Друг получит пустое приложение и вставит свой ключ.
- Хотите платить за друга: создайте на OpenRouter отдельный ключ с лимитом и передайте лично. Отозвать его можно в любой момент, не трогая свой.
- На одном телефоне можно хранить несколько ключей и переключаться между ними (**Настройки → Ключи OpenRouter**).

## Важно знать

- Кладовка, рецепты, покупки и ключи хранятся **только на телефоне**. При смене телефона: **Настройки → Данные → Сохранить копию**, на новом — «Восстановить». Ключи в копию не попадают, их нужно вставить заново.
- Запросы к нейросети уходят в OpenRouter, а оттуда — к выбранной модели. Больше никуда данные не отправляются.
- Без интернета работают кладовка, книга рецептов, покупки и режим готовки. Подбор рецептов и фото требуют сети.

## Как обновить приложение

Загрузите новые файлы в тот же репозиторий поверх старых (**Add file → Upload files**). Данные на телефонах не пропадут. Если обновление не появилось, закройте приложение и откройте снова.
